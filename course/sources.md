## GitHub Copilot in VS Code

| Topic | Source | Notes |
|---|---|---|
| Approvals, terminal auto-approve | https://code.visualstudio.com/docs/agents/run/approvals | A plain string rule matches the start of a command; `/^...$/` rules match exactly. Compound commands need every part approved. "Best-effort convenience, not a security boundary." |
| Custom instructions, `AGENTS.md`, `applyTo` | https://code.visualstudio.com/docs/agent-customization/custom-instructions | Check the References of a response to see which instructions were used. |
| Custom agents (`.agent.md`) | https://code.visualstudio.com/docs/agent-customization/custom-agents | `tools`, `model` (list, first available wins), `handoffs`, `agents`. |
| Tool sets reference | https://code.visualstudio.com/docs/agents/reference/tools-reference | Read-only sets: `search`, `read`. |
| Subagents | https://code.visualstudio.com/docs/agents/run/subagents | A subagent cannot use a more expensive model than its caller. |
| Agent Skills | https://code.visualstudio.com/docs/copilot/customization/agent-skills | `name` and `description` required; call with `/name`. |
| Hooks (Preview) | https://code.visualstudio.com/docs/copilot/customization/hooks | Extension E4 only. |
| MCP configuration | https://code.visualstudio.com/docs/agents/reference/mcp-configuration | `.vscode/mcp.json`, `inputs` for secrets. |
| Context and usage | https://code.visualstudio.com/docs/agents/concepts/context and https://code.visualstudio.com/docs/agents/guides/optimize-usage | Context indicator, `/compact`. |
| AI settings reference | https://code.visualstudio.com/docs/agents/reference/ai-settings | `chat.tools.edits.autoApprove` is a user-level setting. |
