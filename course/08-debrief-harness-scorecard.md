# Debrief and harness scorecard (12 minutes)

## 1. Score your harness (4 minutes)

With your partner, score the set of pull requests you opened, using the
[harness scorecard](rubrics.md#harness-scorecard-debrief). Put one number per dimension on the shared board.

## 2. Spotlight (4 minutes)

The facilitator reviews two pull requests live: what the review agent found, what a human finds, and what CI already caught.

## 3. Credits (2 minutes)

Compare the model, number of requests and context percentage you reported in Labs 2 and 3.
Which task needed a strong model? Which did not?

## 4. Take it home (2 minutes)

For your current client project, write down:

- the one command that tells an agent "done";
- three lines that belong in its `AGENTS.md`;
- one procedure worth a skill;
- one command you would **never** auto-approve, and why.
